# Mrs Robina Appreciation

This repository contains a printable appreciation card for Mrs. Robina.

Files
- `index.html` — improved, print-ready HTML card. Open this file in a browser and use Print → "Save as PDF" or print to a physical A4 page.

Printing tips
- Use a modern browser (Chrome, Edge, Firefox) and select "Paper size: A4".
- In Print settings choose "Scale: 100%" or "Default" and disable headers/footers for a clean output.
- For best color fidelity, enable "Background graphics" / "Background colors and images" in the print dialog.

Notes
- The HTML is self-contained (no external fonts or images) so it will work offline.
- The heart is an inline SVG to ensure consistent printing across platforms.
- Accessibility: the page includes semantic elements and simple ARIA labels for screen readers.
